# Ranobelib Downloader

Скрипт для скачивания книг с ranobelib.me в формате EPUB.

## 🚀 Быстрый старт через GitHub Actions

Вы можете скачать книгу без установки Node.js, используя GitHub Actions:

1. Перейдите на страницу репозитория: https://github.com/aburdeinyy/renobelib-downloader
2. Откройте вкладку **Actions**
3. Выберите **Download Book to EPUB** в левом меню
4. Нажмите **Run workflow**
5. Введите:
   - **Ссылку на книгу** (например: `https://ranobelib.me/ru/book/40218--the-devious-first-daughter`)
   - **Диапазон глав** (опционально, например: `1-150` или `1:1-1:5` или оставьте пустым для всех глав)
6. Нажмите **Run workflow**
7. Дождитесь завершения и скачайте EPUB файл из раздела **Artifacts**

## 📦 Локальная установка

Если вы хотите запускать скрипт локально:

### Требования

- Node.js 16+

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/aburdeinyy/renobelib-downloader.git
cd renobelib-downloader

# Установите зависимости
npm install
```

### Использование

```bash
# Интерактивный режим
node src/downloader.js

# Неинтерактивный режим (через переменные окружения)
BOOK_URL="https://ranobelib.me/ru/book/40218--the-devious-first-daughter" \
CHAPTER_RANGE="1:1-1:5" \
node src/downloader.js --non-interactive
```

## 📖 Формат диапазона глав

### Упрощенный формат (рекомендуется):

- `1-150` - главы 1-150 первого тома
- `1` - только первая глава первого тома

### Полный формат (с указанием тома):

- `1:1` - только первая глава первого тома
- `1:1-1:5` - главы 1-5 первого тома
- `1:1-5` - главы 1-5 первого тома (короткий формат)

### Все главы:

- Пусто - все главы с первой

## 📝 Примеры

### Скачать первые 150 глав:

```
Диапазон: 1-150
```

### Скачать первые 5 глав (полный формат):

```
Диапазон: 1:1-1:5
```

### Скачать все главы:

```
Диапазон: (оставить пустым)
```

## ⚙️ Особенности

- Автоматические паузы между запросами (3 секунды)
- Анимированный прелоадер во время скачивания
- Автоматическое создание EPUB с оглавлением и обложкой
- Поддержка указания диапазона глав (упрощенный и полный формат)
- Обработка ошибок и автоматическое определение конца книги
- Автоматическое скачивание обложки книги
